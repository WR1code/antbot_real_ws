# 四轮转向与行走电机 CAN 控制指令

## 1. 四个位置与 CAN ID

本文规定底盘图纸的上方为车头。转向电机和行走电机使用完全相同的位置编号：

| 物理位置 | 程序简称 | 数组索引 | RS00 转向电机 ID | MINI 行走电机 ID |
| -------- | -------- | -------: | ---------------: | ---------------: |
| 左上     | FL       |        0 |         `0x01` |        `0x005` |
| 右上     | FR       |        1 |         `0x02` |        `0x006` |
| 左下     | RL       |        2 |         `0x03` |        `0x007` |
| 右下     | RR       |        3 |         `0x04` |        `0x008` |

程序中的顺序均为：

```text
FL（左上、1） -> FR（右上、2） -> RL（左下、3） -> RR（右下、4）
```

两种电机可以使用相同的数字 ID，因为 CAN 帧格式不同：

| 电机             | CAN 帧格式  | ID 示例                |        DLC |
| ---------------- | ----------- | ---------------------- | ---------: |
| RS00 转向        | 29 位扩展帧 | 电机 1：`0x1200FD01` |     固定 8 |
| 欧艾迪 MINI 行走 | 11 位标准帧 | 左前轮：`0x005`      | 随命令变化 |

本工程不让两种电机共用物理总线：RS00 使用 FDCAN1/1 Mbit/s，MINI 使用
FDCAN2/500 kbit/s。两对 CAN_H/CAN_L 不得并接。

对应配置位置：

- RS00：[steering_config.h](../firmware/App/Inc/steering_config.h)
- MINI：[drive_config.h](../firmware/App/Inc/drive_config.h)
- 行走安装方向：
  [chassis_translation_controller.c](../firmware/App/Src/chassis_translation_controller.c)

## 2. RS00 转向电机运动指令

RS00 使用主机 ID `0xFD`、29 位扩展数据帧、DLC=8。主机发送 ID 的基本形式：

```text
EXT ID = (通信类型 << 24) | (0xFD << 8) | 电机ID
```

因此电机 1～4 只改变扩展 ID 的最后一个字节：

```text
电机1（左上）：...01
电机2（右上）：...02
电机3（左下）：...03
电机4（右下）：...04
```

### 2.1 停止

| 位置 | EXT ID         | Data                        |
| ---- | -------------- | --------------------------- |
| 左上 | `0x0400FD01` | `00 00 00 00 00 00 00 00` |
| 右上 | `0x0400FD02` | `00 00 00 00 00 00 00 00` |
| 左下 | `0x0400FD03` | `00 00 00 00 00 00 00 00` |
| 右下 | `0x0400FD04` | `00 00 00 00 00 00 00 00` |

`Data[0]=00` 表示只停止；`Data[0]=01` 表示停止并请求清故障。程序不会在原因
不明时自动循环清故障。

### 2.2 设置 CSP 模式

参数 `run_mode` 的索引为 `0x7005`，CSP 值为 `5`。参数索引和值均按小端发送：

```text
电机1 EXT ID：0x1200FD01
Data          ：05 70 00 00 05 00 00 00
```

电机 2～4 把 ID 末字节分别换成 `02/03/04`。

### 2.3 设置 CSP 安全限速和限流

```text
限速 1.0 rad/s，参数 0x7017：
EXT ID：0x1200FD01
Data  ：17 70 00 00 00 00 80 3F

限流 2.0 A，参数 0x7018：
EXT ID：0x1200FD01
Data  ：18 70 00 00 00 00 00 40
```

最后四字节是 IEEE-754 `float` 小端：

```text
1.0f -> 00 00 80 3F
2.0f -> 00 00 00 40
```

### 2.4 写入转向位置目标

CSP 位置目标 `loc_ref` 的参数索引为 `0x7016`，单位为 rad。以左上电机转到
`1.0 rad` 为例：

```text
EXT ID：0x1200FD01
Data  ：16 70 00 00 00 00 80 3F
```

四轮分别写入时：

| 位置 | EXT ID         | Data[0..3]      | Data[4..7]            |
| ---- | -------------- | --------------- | --------------------- |
| 左上 | `0x1200FD01` | `16 70 00 00` | 左上目标角 float 小端 |
| 右上 | `0x1200FD02` | `16 70 00 00` | 右上目标角 float 小端 |
| 左下 | `0x1200FD03` | `16 70 00 00` | 左下目标角 float 小端 |
| 右下 | `0x1200FD04` | `16 70 00 00` | 右下目标角 float 小端 |

程序在 READY 状态每 20 ms 刷新位置目标。目标角先经过每个轮子的方向符号和
零偏校准，再检查机械安全范围；不能直接把未经标定的车体角度原样发送。

### 2.5 使能

```text
左上：EXT ID 0x0300FD01，Data 00 00 00 00 00 00 00 00
右上：EXT ID 0x0300FD02，Data 00 00 00 00 00 00 00 00
左下：EXT ID 0x0300FD03，Data 00 00 00 00 00 00 00 00
右下：EXT ID 0x0300FD04，Data 00 00 00 00 00 00 00 00
```

安全启动顺序是：

```text
停止 -> 查询 UID -> 读取当前位置 -> 设置并读回 CSP 参数
-> 预装当前位置为 loc_ref -> 进入 ARMED
-> 显式请求使能 -> 进入 READY -> 周期写 loc_ref
```

## 3. 欧艾迪 MINI 行走电机运动指令

MINI 使用 11 位标准数据帧。CAN ID 就是驱动器地址，命令放在 `Data[0]`。
多字节控制值使用大端，控制命令本身没有独立应答。

### 3.1 心跳

四台驱动器都必须单独周期发送心跳：

| 位置 | 标准 CAN ID | DLC | Data   |
| ---- | ----------: | --: | ------ |
| 左上 |   `0x005` |   1 | `00` |
| 右上 |   `0x006` |   1 | `00` |
| 左下 |   `0x007` |   1 | `00` |
| 右下 |   `0x008` |   1 | `00` |

程序当前每台不超过 100 ms 刷新一次。欧艾迪上位机中的心跳超时时间必须大于
这个周期并留出足够裕量。

### 3.2 设置速度环加速度

```text
标准 CAN ID：对应行走驱动器 ID
DLC          ：5
Data         ：0A aa bb cc dd
```

`aa bb cc dd` 是正数 `int32` 大端，按欧艾迪 CAN 指令文档填写的单位为
`erpm/s²`。

按当前实机配置，`0.20 m/s²` 换算结果约为 `364 erpm/s`：

```text
左上示例：ID 005，DLC 5，Data 0A 00 00 01 6C
```

电机 2～4 使用相同 Data，只改变标准 CAN ID。

### 3.3 设置速度环减速度

```text
标准 CAN ID：对应行走驱动器 ID
DLC          ：5
Data         ：10 aa bb cc dd
```

按当前实机配置，`0.30 m/s²` 换算结果约为 `546 erpm/s`：

```text
左上示例：ID 005，DLC 5，Data 10 00 00 02 22
```

### 3.4 设置行走速度

```text
标准 CAN ID：对应行走驱动器 ID
DLC          ：5
Data         ：02 ss ss ss ss
```

速度是有符号 `int32` 大端，单位为 `erpm`：

```text
正数：正向旋转
负数：反向旋转，使用二进制补码
零  ：速度环按减速度把电机控制到停止
```

程序输入为轮缘线速度 `m/s`，换算公式：

```text
erpm = m/s / (2π × 轮径) × 60 × 电机到车轮减速比 × 电机极对数
```

按当前实机配置（轮胎半径 `0.0525 m`、减速比 `1:1`、极对数 `10`），
`+0.05 m/s` 约等于 `+91 erpm`：

```text
左上正转：ID 005，DLC 5，Data 02 00 00 00 5B
左上反转：ID 005，DLC 5，Data 02 FF FF FF A5
```

其余三个位置只改变标准 CAN ID：

```text
右上 ID 006
左下 ID 007
右下 ID 008
```

程序每台不超过 50 ms 刷新速度目标。

### 3.5 普通停止

普通停止保持速度闭环，按已设置的 `0x10` 减速度降到零：

```text
ID 005/006/007/008，DLC 5，Data 02 00 00 00 00
```

### 3.6 急停撤流

急停切换到零电流输出：

```text
ID 005/006/007/008，DLC 3，Data 01 00 00
```

零电流表示撤销输出，不等同于电子刹车。程序不会在高速时直接使用手刹
`0x09`。急停后程序停止发送心跳，使驱动器自身的通信超时保护也能介入。

### 3.7 主动安全查询

控制程序会主动轮询故障、转速、电压、电机电流和温度，不依赖驱动器是否保存了
异步回传配置。转速已纳入停车判定：四轮必须连续 100 ms 低于 30 erpm。

| 查询内容 | 请求 Data | 返回 Data | 数值 |
|---|---|---|---|
| 故障 | `0F 00` | `0F 00 xx xx` | `uint16` 大端，单一故障码 0～19 |
| 速度 | `0F 01` | `0F 01 xx xx xx xx` | `int32` 大端，erpm |
| 电压 | `0F 04` | `0F 04 xx xx` | `uint16` 大端，V |
| 电机电流 | `0F 05` | `0F 05 xx xx` | `int16` 大端，10 mA |
| 温度 | `0F 07` | `0F 07 xx xx` | `int16` 大端，°C |

```text
请求：ID 005/006/007/008，DLC 2，Data 0F 01
返回：同一标准 ID，DLC 6，Data 0F 01 + int32大端erpm
```

## 4. 底盘平移时两种电机的配合顺序

应用层不要直接同时给转向角和行走速度。正确顺序为：

```text
1. 四个 MINI 行走电机发送速度 0
2. 等待四轮实测速度连续 100 ms 不超过 30 erpm；未建立过完整反馈的架空标定
   阶段才允许减速度估算回退，整车行走仍保持锁定
3. 四个 RS00 写入新的 CSP 转向角
4. 等待四个 RS00 的位置误差和速度连续 100 ms 满足对准条件
5. 四个 MINI 按 5/6/7/8 的对应关系发送行走速度
6. 周期刷新 RS00 位置、MINI 心跳和 MINI 速度
7. 命令超过 300 ms 未刷新时，把 MINI 速度降为 0
```

程序调用接口：

```c
/* direction_deg: 0=前，90=左，180=后，270=右 */
ChassisTranslation_CommandDirection(direction_deg, speed_mps);

/* 或直接使用车体平移速度 */
ChassisTranslation_CommandVelocity(vx_mps, vy_mps);
```

第一次实机测试必须四轮架空，并从 `0.03~0.05 m/s` 开始。CAN ID 对应正确并不
代表电机机械正方向一定正确；四个 `s_drive_install_sign` 仍需逐轮实测。
