# 欧艾迪 MINI 与 4 寸轮毂电机实机参数

本表用于本工程配置和实机调试，协议依据为
[《4-17 CAN 编程手册 V1.2》](4-17-CAN编程手册.pdf)。

## 电机与驱动器

| 参数 | 实机值 |
|---|---:|
| 电机 | 24 V、150 W 无刷直流轮毂电机 |
| 轮胎直径/程序半径 | 105 mm / 0.0525 m |
| 磁极对数 | 10 |
| AB 编码器配置值 | 4096 |
| 电机额定转速 | 200～400 rpm |
| 电机额定/峰值电流 | 8 A / 17 A |
| 驱动器持续/最大电流 | 4 A / 8 A |
| 驱动器速度上限 | 12400 erpm = 1240 rpm（配置上限） |
| 传动比 | 轮毂直驱，1:1 |

`4096` 按上位机编码器配置值记录，程序当前不把它直接解释为轮子机械一圈的
脉冲数。底盘速度换算只使用轮胎半径、传动比和极对数。

## CAN 配置

| 位置 | ID | 总线 |
|---|---:|---|
| 左上 FL | 5 | FDCAN2，500 kbit/s |
| 右上 FR | 6 | FDCAN2，500 kbit/s |
| 左下 RL | 7 | FDCAN2，500 kbit/s |
| 右下 RR | 8 | FDCAN2，500 kbit/s |

四台均设置发送 ID 等于接收 ID，驱动器自带 120 Ω 终端关闭；整条总线仅在线缆
两端安装两个 120 Ω 终端。心跳超时为 1000 ms，STM32 每台不超过 100 ms
发送一次 `00` 心跳。

## 周期反馈

实机测得启用四台高频异步回传时，接收速率约为 `1268 frame/s`，并会因驱动器
回传与 STM32 命令使用相同 CAN ID 而产生长期发送争用。生产配置应把上位机
“CAN 总线”页中的全部“信息回传时间”设为 `-1 ms`（关闭异步回传），写入应用
参数并重启驱动器。安全反馈由 STM32 的同步查询获得。

| 反馈 | 驱动器异步上报 | 程序解析 |
|---|---:|---|
| 故障 `0F 00` | `-1 ms` | `fault_code`（单一故障码） |
| 速度 `0F 01` | `-1 ms` | `speed_erpm` |
| 电机电流 `0F 05` | `-1 ms` | `motor_current_10ma` |
| 位置 `0F 08` | `-1 ms` | `position_centideg`（非安全必需） |
| 温度 `0F 07` | `-1 ms` | `temperature_c` |

调试器可直接观察 `g_drive_feedback[0..3]`，顺序固定为 FL、FR、RL、RR。
固件主动轮询 `0F 00/01/04/05/07`，不依赖异步回传。四台驱动器的
故障、速度、电压、电流、温度必须全部收到，非零行走命令才会接受。按实机上报
周期分层判定：速度/电流 250 ms、故障 500 ms、温度 750 ms、电压 2 s。
首次建立完整反馈后，任一反馈过期、驱动器故障、绝对电流超过 8 A、温度达到
85 °C、电压离开 36～60 V 或速度超过 1500 erpm，都会进入锁存急停。

停车优先使用实测转速：四轮连续 100 ms 不超过 30 erpm 才允许开始转向。
只有尚未建立过完整反馈的上电调试阶段才使用减速度估算，而且整车行走仍保持
锁定。故障返回值是手册中的单个故障码 `0..19`，不是可任意组合的 bitmask。

## 仍需实机标定

- 四个行走轮的安装正反方向；上位机里的 `电机方向=False` 不能代替装车后的
  前进方向检查。
- RS00 四轮零偏、方向符号和带安全余量的机械最小/最大位置。
- 底盘允许的最大线速度和期望加减速度；程序暂保留保守的 0.5 m/s、
  0.2 m/s²、0.3 m/s²。
