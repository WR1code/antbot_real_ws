# 接线说明

## 必须使用 CAN 收发器

STM32 的 `PB8/PB9` 是 3.3 V 逻辑信号，不能直接接 RS00 的 `CAN_H/CAN_L`。
必须使用 CAN 收发器，例如：

- 3.3 V 收发器：SN65HVD230 一类器件；
- 带独立 3.3 V `VIO` 的 5 V 收发器。

不要把输出为 5 V 的收发器 RXD 直接送入 STM32。若模块带 `STB/EN`，还必须把
它设置为正常工作状态，不能悬空。

## 核心板排针位置

以下编号来自 `FK743M2-IIT6` 排针版原理图和 V1.1 引脚说明，不是 STM32 芯片的
BGA 管脚号：

| 信号 | 核心板排针编号 | 本工程用途 |
|---|---:|---|
| PB8 | 43 | FDCAN1_RX，RS00 |
| PB9 | 46 | FDCAN1_TX，RS00 |
| PB12 | 82 | FDCAN2_RX，MINI |
| PB13 | 79 | FDCAN2_TX，MINI |
| PA9 | 64 | USART1_TX，发往 Linux |
| PA10 | 62 | USART1_RX，接收 Linux |
| PA13 | 63 | SWDIO |
| PA14 | 61 | SWCLK |
| 5V | 5 或 6 | 核心板电源输入，只选一处接入 |
| 3.3V | 59 或 60 | 逻辑电源/电平参考，不接电机电源 |
| GND | 1/2/3/4/57/58/112 | 信号参考地，按布线就近选用 |

焊接前要用正反面丝印再次确认方向；不要只按“从左数第几个孔”定位。

## 两条 CAN 信号连接

```text
RS00 总线（收发器 A）：
FK743 PB9  / 排针46 (FDCAN1_TX) -> 收发器 A TXD
FK743 PB8  / 排针43 (FDCAN1_RX) <- 收发器 A RXD
收发器 A CAN_H                  -> RS00 总线 CAN_H
收发器 A CAN_L                  -> RS00 总线 CAN_L

MINI 总线（收发器 B，不能与 A 的 H/L 并接）：
FK743 PB13 / 排针79 (FDCAN2_TX) -> 收发器 B TXD
FK743 PB12 / 排针82 (FDCAN2_RX) <- 收发器 B RXD
收发器 B CAN_H                  -> MINI 总线 CAN_H
收发器 B CAN_L                  -> MINI 总线 CAN_L

两只非隔离 3.3 V 收发器：
FK743 3V3 -> VCC/VIO；FK743 GND -> GND
各执行器通信地 -> 对应总线参考地
```

推荐在电机、高压和长线环境使用两只独立隔离 CAN 收发器。隔离模块的 MCU 侧必须是
3.3 V 逻辑；总线侧电源和地严格按模块说明连接，不能自行跨接隔离栅两侧的地。常见
TJA1050 模块通常使用 5 V 逻辑，除非模块明确提供 3.3 V `VIO`，否则不能直接接 H743。

总线拓扑：

```text
FDCAN1 收发器 A == RS00 FL == RS00 FR == RS00 RL == RS00 RR
FDCAN2 收发器 B == MINI  FL == MINI  FR == MINI  RL == MINI  RR
```

每行表示一条独立的干线，节点短支接；不是把所有节点拉回主控形成星形。

## USART1、SWD 和供电

USB-TTL 必须是 3.3 V TTL 电平并交叉连接：

```text
USB-TTL TX  -> PA10 / 排针62 / USART1_RX
USB-TTL RX  <- PA9  / 排针64 / USART1_TX
USB-TTL GND -> FK743 GND
```

不要连接 USB-TTL 的 5 V 电源脚，也不能使用 RS-232 正负电压口。核心板已经有标注
`RX/TX/RST/3V3` 的调试排针，背面丝印中的 `TX` 对应 PA9、`RX` 对应 PA10。
核心板 Type-C 的数据线连接 PA11/PA12，是 USB/DFU 口，不是 USART1 串口；若已经
通过 Type-C 给核心板供电，不要再从排针 5/6 并联注入另一路 5 V。

SWD：`SWDIO/DIO -> PA13`、`SWCLK/CLK -> PA14`、`GND -> GND`。核心板由自己的
稳定 5 V 电源供电时，不要再由下载器 5 V 反向供电；若下载器需要目标电压检测，
只把核心板 3.3 V 接到下载器 `VTref`，不要由 `VTref` 向板上灌电。

电机动力电源与核心板供电分开：

- RS00 手册给出的工作电压范围是 `24–60 VDC`，额定电压 `48 VDC`；
- FK743 核心板建议只从一个入口使用稳定的 `5 V` 输入，由板载稳压器产生 3.3 V；
- 禁止把电机动力电压接到核心板 5 V/3.3 V 引脚。

RS00 动力电压和 MINI 的 24 V 动力回路分别按各自铭牌、驱动器手册、线径和保险丝
设计。实体急停应通过额定合适的安全继电器/接触器直接撤去驱动器 ENABLE 或切断
电机动力；不能只发 CAN/UART 停止命令。控制板建议保持供电，以便记录故障。

## 终端与布线

- 总线只在线缆两端各放一个 `120 Ω` 终端电阻。
- 断电后测量 CAN_H 与 CAN_L，典型总阻值约 `60 Ω`（两个 120 Ω 并联）。
- CAN_H/CAN_L 使用双绞线，首次测试尽量缩短支线。
- 一台电机加一个主控同样需要两端终端。
- 收发器模块和电机内部是否已经带终端必须实际确认，不能重复叠加。

## 上电前万用表检查

1. 电机动力正负极无短路，极性正确。
2. 核心板 5 V、3.3 V 对地无短路。
3. PB8/PB9 没有接到 CAN_H/CAN_L。
4. CAN_H 与 CAN_L 之间终端阻值合理。
5. RS00 总线全部为 `1 Mbit/s`，MINI 总线全部为 `500 kbit/s`。
6. 两条 CAN 的 CAN_H/CAN_L 没有互相导通，且没有 H/L 接反。
7. USB-TTL 是 3.3 V TTL，TX/RX 已交叉，未连接其 5 V 脚。
8. 实体急停可在 STM32 和 Linux 都失效时直接撤去电机动力或使能。
