# RS00 CSP 0～180°转向与纯平移控制

## 功能边界

本实现只处理底盘纯平移。RS00 是转向电机，`loc_ref` 是机械位置目标，
绝不是行走速度。四个行走电机通过独立 `drive_controller` 接口控制。

行走电机已按《欧艾迪 MINI 驱动器 CAN 指令详解 DMTool 版 V1.0》接入。
RS00 使用 29 位扩展帧、固定 DLC=8；欧艾迪 MINI 使用 11 位标准帧，命令字
位于 `Data[0]` 且 DLC 随命令变化。RS00 独立使用 FDCAN1（1 Mbit/s），MINI
独立使用 FDCAN2（500 kbit/s），因此不能把两类电机接到同一对 CAN_H/CAN_L。
两类电机的数组和物理位置顺序均固定为左上/FL、右上/FR、左下/RL、右下/RR；
RS00 对应 ID `1/2/3/4`，MINI 对应 ID `5/6/7/8`。

当前行走控制发送：

| 功能 | MINI Data | DLC | 程序行为 |
|---|---|---:|---|
| 心跳 | `00` | 1 | 每台不超过 100 ms 刷新；驱动器超时 1000 ms |
| 速度目标 | `02 + int32 BE` | 5 | 每台不超过 50 ms 刷新 |
| 加速度 | `0A + int32 BE` | 5 | 初始化时逐台设置 |
| 减速度 | `10 + int32 BE` | 5 | 初始化时逐台设置 |
| 急停撤流 | `01 00 00` | 3 | 逐台发送，停止后不再发心跳 |

普通停止发送速度目标 0，让速度环按 `0x10` 的减速度降速。急停发送电流目标
0，撤销输出；按协议这不是电子刹车。程序没有在高速时使用 `0x09` 手刹。

MINI 控制命令本身没有应答，因此固件主动轮询 `0F 00/01/04/05/07`。完整、新鲜
且通过阈值检查的四轮反馈是非零行走命令的前置条件。`AllWheelsStopped()` 优先
要求四轮实测转速连续 100 ms 不超过 30 erpm，不把“目标清零”当成物理瞬停。

## 坐标与方向映射

- 0°：车体前方 `+X`
- 90°：车体左方 `+Y`
- 180°：车体后方 `-X`
- 270°：车体右方 `-Y`
- 逆时针为正；输入先归一化到 `[0, 360)`

本车以四个轮子物理对准车头的位置作为逻辑转向 0°，此时配合行走正转朝
车体前方。正转方向与逻辑转向角的关系为 `direction = -steering`。轮胎朝向
是一条无向轴线，0～180°逻辑舵角再配合行走轮正反转，可以覆盖完整 360°
平移方向；RS00 本身允许连续旋转。

| 平移方向 | 转向角 | 行走方向 |
|---:|---:|:---|
| 0° | 0° | 正 |
| 45° | 135° | 反 |
| 90° | 90° | 反 |
| 135° | 45° | 反 |
| 180° | 0° | 反 |
| 181° | 179° | 正 |
| 225° | 135° | 正 |
| 270° | 90° | 正 |
| 315° | 45° | 正 |
| 359° | 1° | 正 |
| 360° / 720° | 0° | 正 |
| -90° | 90° | 正 |

程序严格保持目标方向，不把 359°近似成 0°。正后方 180°优先使用“舵角 0°、
行走反转”的等效解，因此前进切换后退不需要将舵轮旋转 180°。方向改变时程序
仍必须先停止行走、完成转向，再恢复移动；底层
会选择离当前保持目标最近的等效圈数，避免编码器跨圈后额外旋转一整圈。

`ChassisTranslation_CommandVelocity(vx, vy)` 使用
`sqrt(vx²+vy²)` 和 `atan2(vy,vx)`。速度低于
`CHASSIS_SPEED_DEADBAND_MPS` 时只停止行走，不改变舵角。

## CSP 启动过程

启动状态机依次执行：

1. 等待电机启动；
2. 向四台 RS00 发送停止；
3. 查询并检查 UID；
4. 读取各自 `mechPos`；
5. 检查位置值有限；仅在启用机械限位检查时再核对各轮 `[min,max]`；
6. 每台写入并读回 `run_mode=5`；
7. 每台写入并读回 `limit_spd=1.0 rad/s`；
8. 每台写入并读回 `limit_cur=2.0 A`；
9. 写入并读回 CAN 超时；
10. 把各台自身当前位置预装为其 `loc_ref` 并读回；
11. 进入 `ARMED`，保持禁用；
12. 显式请求后逐台使能，全部验证通过才进入 `READY`。

模式切换前已经停止全部电机，绝不在 PP 运行中直接切换。启动状态机不再写
PP 专用的 `vel_max (0x7024)` 或 `acc_set (0x7025)`。工程也不修改 CAN ID、
机械零位、`zero_sta`、`add_offset`、协议、波特率或电机 Flash。

关键完整帧（29 位扩展 ID、CAN 2.0、DLC=8、1 Mbit/s）：

| 操作 | ID（电机 1） | Data |
|---|---|---|
| 停止 | `0x0400FD01` | `00 00 00 00 00 00 00 00` |
| CSP 模式 | `0x1200FD01` | `05 70 00 00 05 00 00 00` |
| 限速 1.0 | `0x1200FD01` | `17 70 00 00 00 00 80 3F` |
| 限流 2.0 | `0x1200FD01` | `18 70 00 00 00 00 00 40` |
| 使能 | `0x0300FD01` | `00 00 00 00 00 00 00 00` |

电机 2～4 只把 ID 末字节换成 `02`～`04`。`loc_ref` 的 Data 前四字节是
`16 70 00 00`，后四字节是目标 rad 的 IEEE-754 `float` 小端表示。所有
float 编解码均使用 `memcpy`，不做未对齐类型转换。

## 机械范围与标定

逻辑舵角先经过每轮安装标定：

```text
motor_angle = direction_sign * logical_angle + zero_offset_rad
```

启用机械限位检查时，随后再次检查该轮的 `min_angle_rad` 和 `max_angle_rad`。
本车已经解除 360°机械限制，所以该检查关闭；固件根据当前保持目标选择最近的
等效电机角，保证跨越编码器圈边界时目标连续。

需要逐轮架空标定：

1. 把轮子物理对准车头，记录逻辑 0°对应的真实位置并填写 `zero_offset_rad`；
2. 用小步进确认正逻辑角是否令机械角增加，填写 `direction_sign`；
3. 确认线束留量允许机构连续旋转且不会缠绕；
4. 在 `drive_config.h` 中核对四台行走驱动器 CAN ID、轮径、电机到车轮减速比
   和电机极对数；
5. 对每个行走轮发极低速命令，填写 `drive_install_sign`，不能根据左右安装
   方式猜测。

若以后重新安装机械限位，必须先实测并留出装配误差、编码器噪声和机构回差
余量，再开启 `STEERING_ENABLE_MECHANICAL_LIMIT_CHECK`。

## 执行状态机与安全行为

控制流程为：

```text
IDLE
 -> STOPPING_DRIVE（行走目标清零并等待停止）
 -> STEERING（写四轮 CSP 目标）
 -> WAIT_ALIGNMENT（保持目标并检查四轮）
 -> DRIVING
```

每轮必须保持位置误差不超过 `0.03 rad` 并连续稳定 `200 ms`。实机发现 RS00
速度反馈在位置稳定后仍有量化残值，因此不再用瞬时速度值阻止到位；连续位置
窗口仍可排除快速穿越目标的情况。等待超过 `5000 ms` 会停止四台 RS00 和
所有行走轮，进入故障并记录首个未对准轮。5 秒也覆盖了限速 1 rad/s 时理论上
需要约 3.14 秒的完整 180°逻辑转向。

运动中收到明显新方向时立即清零行走目标，等全部停止后才写新转向目标。
任何一个转向电机故障、离线、反馈超过 `500 ms`、机械越界，都会停止全部转向
和行走。该门限与 RS00 配置的约 500 ms CAN 超时一致；发生故障时会锁存四轮
最后反馈年龄，可用 `control_tool.py rs00-feedback-age` 查询。首次越过门限只进入
100 ms 连续确认窗口；CAN 中断在窗口内刷新反馈会取消待定故障，只有时间戳在
整个窗口内确实没有变化才锁存停车，避免超时检查与接收中断之间的竞态误报。
`DRIVING` 状态超过 `300 ms` 未收到新命令会停止行走，但保持最后安全舵角。
急停立即停止行走、发送四台 RS00 停止帧并进入不可自动恢复的故障状态。

READY 时 `loc_ref` 每 20 ms 刷新，不在主循环无间隔发送。
`STEERING_AUTO_ENABLE=0` 且 `CHASSIS_AUTO_ENABLE_AFTER_STARTUP=0`，首次烧录
不会自动使能。`STEERING_CALIBRATION_CONFIRMED=0` 时整车平移命令还会被额外
锁定，仅允许每次不超过 0.01 rad 的架空转向标定。

## 第一次架空测试

1. 四轮全部架空，人员远离机构并准备物理断电；
2. 保持两个自动使能宏为 0；
3. 上电确认四台停在 `ARMED`；
4. 确认 `run_mode=5`、`limit_cur≈2.0 A`、`limit_spd≈1.0 rad/s`；
5. 确认四个当前位置有限，且线束不会因连续转向而缠绕；
6. 显式调用 `SteeringController_RequestEnable()`；
7. 保持行走目标为 0，用不超过 0.01 rad 的小步确认四轮安装方向；
8. 方向确认后测试纯平移映射：前进为逻辑 0°正转，向左为逻辑 90°反转；
9. 第一次行走只使用很低速度，并用 CAN 分析仪核对实际标准帧；
10. 任意异常立即急停并切断动力。

当前 `drive_config.h` 按 CAN ID `5/6/7/8`、轮胎直径 `0.105 m`（半径
`0.0525 m`）、轮毂直驱 `1:1`、极对数 `10` 编译。驱动器最大速度配置为
`12400 erpm`；按手册换算为 `1240 rpm`，它是配置上限而不是建议持续转速。
速度换算为：

```text
erpm = m/s ÷ (2π × 轮径) × 60 × 减速比 × 极对数
```

默认最大命令限制为 `0.5 m/s`，但第一次架空测试仍应只发
`0.03~0.05 m/s`。MINI 上位机必须设置为普通 CAN（不是 CANopen），四台地址
依次为 5/6/7/8、波特率为 500 kbit/s，心跳超时设为 1000 ms。
