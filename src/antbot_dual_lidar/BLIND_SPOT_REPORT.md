# 盲区量化报告

当前已知的几何/运行事实：两传感器为 360°、垂直 -15°…+10°，光学原点分别为
`(0.322,0.222,0.414)` 和 `(-0.322,-0.222,0.414)`，后者 yaw 为 π；车体过滤
box 是 `x[-0.43,0.43] y[-0.29,0.29] z[-0.10,0.45]`。navigation 首帧车体
过滤两路各移除 76 点，mapping 为 954/969 点。这个数量证明存在近车体回波，但
不能单独推出水平遮挡区间。

状态：**已完成静止 demo 的 observed-return 分桶；没有完成环形障碍/射线真值
GUI 试验，因此几何共同盲区和各运动方向可靠覆盖角仍为 PENDING。**

已新增可验证的 1° 极坐标分桶工具：

```bash
ros2 run antbot_dual_lidar coverage_probe --duration 30 \
  --bin-degrees 1 \
  --output /home/w/project/antbot/isaac/reports/blind_spot_metrics.csv
```

实际输出为 `isaac/reports/blind_spot_metrics.csv`。navigation 下采集 42 帧：

| 指标（1° sensor-local 桶） | front | rear |
|---|---:|---:|
| 有回波角桶 | 331/360 | 331/360 |
| 连续零回波区 | -158°…-129° | -158°…-129° |
| 最小观测回波距离 | 0.39997 m | 0.39984 m |

rear frame 相对 base yaw=180°，所以换算到 base 后 rear 的零回波区为约
22°…51°；front 为 -158°…-129°。这两个 demo observed gap 不重叠，按桶统计的
双雷达 observed union 为 360°、共同有回波约 302°。这只是当前四墙/障碍场景
42 帧的可复现观测，不等于传感器几何视场保证，也不能把 0.40 m 当作“最小可靠
检测距离”。

CSV 对每颗雷达/角桶给出帧数、回波数、每帧平均回波、最小距离和 z 范围。零回波
桶可能由场景无表面、材质、量程或真实遮挡造成，必须与不同高度（0.05、0.20、
0.45、0.80 m）的圆周测试物配合，不能直接当作盲区。正式量化流程是在半径
0.25–3.0 m、每 5° 放置测试物，分别运行单雷达/双雷达，并将检测阈值、共同盲区、
重叠区、前后左右有效覆盖和最小可靠距离填写到新的 CSV，并与本次静态 demo
基线对比，避免把“无表面”误标为传感器盲区。
