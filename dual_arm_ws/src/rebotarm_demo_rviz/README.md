# reBotArm RViz 机械臂控制面板

真机 DM 版一键启动命令：

```bash
source /home/w/project/rebotarm/real_robot_ws/activate.sh && ros2 launch rebot_xbox_hardware xbox_hardware_servo.launch.py model:=dm channel:=/dev/ttyACM2
```

没有连接真实机械臂时，如需保留 `reBotArm / Piper-H` 机械臂选择页，使用双臂离线入口：

```bash
source /home/w/project/rebotarm/real_robot_ws/activate.sh
ros2 launch rebot_xbox_hardware dual_arm_offline_preview.launch.py rebot_model:=dm
```

它会同时启动两种假硬件模型、MoveIt、RViz 双臂统一工作台和现有动作库，但不会启动
串口/CAN 驱动或 Xbox。RViz 只保留这一个整机工作台入口；顶层为机械臂选择、机械臂控制和底盘控制，原运动规划
都在其内部切换。
在“演示与动作 → 动作组编排”选择任一动作组，点击“播放勾选动作的 RViz 动画”即可看到
模型动作，不需要真实机械臂、Xbox 或相机。离线模式会在“真机与安全”页明确标识，并禁用
动作组的真机回放。不要与真机组合 launch 同时运行。

该入口加载本面板。相机、手部视觉、手眼标定和把脉预接触功能均从面板按钮启动，
不需要另外运行它们各自的 launch。

这个 RViz 面板把 MoveIt `MotionPlanning` 的必要功能、真机快捷操作、示教和动作编排
整合到一个面板中。顶层页面重新分为：

- **真机与安全**：连接状态、关节反馈、MoveIt 有效性、Xbox 控制权和三维禁区管理；
- **演示与动作**：共享动作选择器，并细分为“单动作与形状”“动作组编排”和
  “自由运动规划”；自由规划嵌入原生 MotionPlanning 的上下文、规划和关节页面；
- **摄像头**：可检索当前 ROS 图像话题并选择要显示的摄像头，显示 Gemini 2 画面并控制
  由本面板启动的摄像头进程。
- **手部视觉**：在标签页内显示手部视觉发布的 RGB 标注图（原三联画面最左侧），并可启动/停止视觉处理；
  面板启动时使用无窗口模式，画面只显示在当前标签页；画面包含 MediaPipe 关键点、深度、腕部
  轮廓和稳定手势事件。手势只作为演示请求，不会自动使能机械臂。
- **手眼标定**：可选择“眼在手外（固定相机）”或“眼在手上（末端相机）”，填写机器人与
  标记跟踪 TF frame、选择 AprilTag 家族后启动 `easy_handeye2`，完成采样、计算和保存；
  标定前必须先现场确认 TF 树和物理安装方式。

手眼标定页现在会同时启动 AprilTag 跟踪和 `easy_handeye2`。可选择 `16h5`、`25h9`、
`36h11`、`Circle21h7`、`Circle49h12`、`Custom48h12`、`Standard41h12` 或
`Standard52h13`（默认 `36h11`）；选择家族后 ID 输入范围会自动更新。眼在手外时相机固定、
标签装在夹爪上；眼在手上时相机刚性安装在末端、标签固定在环境中。采集至少 12 个覆盖
多轴旋转的姿态，点击 Compute 和 Save，再点击停止标定；保存的
`~/.ros2/easy_handeye2/calibrations/<名称>.calib` 会按所选模式发布正确的静态标定 TF。
标定目标还可选择仓库根目录的 `ChArUco_A4_HandEye_Print_100pct.pdf`；该模式固定采用
`DICT_4X4_50`、5 × 7 棋盘、35 mm 方格和 26 mm Marker，直接从去畸变彩色图像估计
整板位姿，因此界面中的 AprilTag 家族、ID 和尺寸输入会被锁定。打印时必须选择
100% / Actual Size，并用页面顶部的 100 mm 校验线核对打印机没有缩放。

“标定包”下拉框提供 `easy_handeye2` 和 `MoveIt Calibration`。选择后者会锁定上述
ChArUco 板并在当前 RViz 打开 MoveIt Calibration 窗口，自动填写 5 × 7、
`DICT_4X4_50`、245 mm 最长边、26 mm Marker、相机话题和所选标定布局。请在插件中再次
确认 Context 页的 4 个 frame 与 `arm` 规划组，再在 Calibrate 页手动采样和保存。
当前该后端只为 reBotArm 启用，且不连接项目的自动采样动作组。

DM 动作库内置命名动作组 **“自动手眼标定_DM_12姿态”**，仍在“演示与动作 → 动作组编排”
的原有下拉框中选择。先启动手眼标定并确认 `marker_frame` 连续可见，再完整播放该动作组的
RViz 动画；确认 12 个姿态均在相机视野与现场安全空间内后，将 Xbox 设为 `LOCKED`，勾选
全部 12 个子动作并执行真机回放。系统会先用 MoveIt 规划进入首姿态和全部姿态间过渡，
在每个目标停稳后检查 AprilTag/机器人 TF、自动采样，最后自动 Compute、Save、停止标定
并加载保存的 TF。TF 丢失、有效采样不足、规划失败或回放故障都会中止流程，不会跳过失败
姿态继续计算。该预设仅适用于 DM 模型；相机应能覆盖 TCP 约
`X=0.39..0.46 m, Y=-0.15..0.03 m, Z=0.25..0.42 m` 的区域，现场禁区仍以 RViz/MoveIt
预检结果为准。

眼在手上请选择 **“自动手眼标定_DM_眼在手上_12姿态”**。这套动作同样包含 12 个多轴
静止采样姿态，但摆动更小，以降低末端相机丢失固定标签的概率。先把相机刚性安装到末端，
再把标签固定在中心姿态可见的环境位置；该动作组的 `gripper_tcp` 位置约覆盖
`X=0.413..0.456 m, Y=-0.129..0.002 m, Z=0.243..0.410 m`。标签需在全部姿态中完整可见、
留有边缘余量且不过曝。
相机外壳和线缆若未包含在 MoveIt 碰撞模型中，现场仍须额外留出安全余量。面板会把该模式传给
`easy_handeye2` 的 `eye_in_hand` 配置，并拒绝用眼在手外动作组启动自动采样。两种模式建议使用
不同标定名称，面板默认将眼在手上的名称改为 `rebotarm_camera_eye_in_hand`，防止覆盖原结果。

Piper-H 动作库会自动补齐两套独立预置：**“自动手眼标定_PiperH_12姿态”**和
**“自动手眼标定_PiperH_眼在手上_Link5_18姿态”**。Piper-H 腕部相机固定在关节 6 之前，因此眼在手上以
`piperh/Link5` 为末端基准，且预置姿态不再旋转 joint6。眼在手外包含 12 个、眼在手上包含 18 个符合 Piper-H 关节限位的三秒
静止采样动作，不复用 DM 关节角。首次现场使用仍必须完整播放 RViz 预览，并确认相机视野、
末端工装、线缆和现场禁区在全部姿态及姿态间过渡中安全。

手部视觉页会在稳定检测到近似桡侧腕部把脉区域时显示绿色 `PULSE READY` 和三维相机坐标。
点击“识别把脉区并前往预接触位”前必须确认手眼标定已保存、探头安装方向正确、Xbox 为
`LOCKED`；程序会进行 TF、工作区和 MoveIt 碰撞检查，并只移动到距离皮肤的预接触位。
Piper-H 会保持手动设定的 J6 姿态，使用包含 115.99 mm 探头的模型生成最大 80 mm 的
直线修正；运动前取当前无接触压强基线，运动中监控三路压强、目标变化和控制权。
当前版本不会接触人体，也不会施加把脉压力；力传感器和柔顺控制需另行集成与验证。

“演示与动作”页新增“脱离奇异位形（关节空间）”：J1–J6 可自定义，DM 默认值为
`[0.0, -1.60, -0.90, -0.90, 0.50, 0.0] rad`。该姿态的几何 Jacobian 条件数约为
`11.47`，末端约位于 `base_link` 的 `[0.445, -0.067, 0.326] m`，保持在桌面上方并收在
基座前方。必须先将 Xbox 设为 `LOCKED`；按钮会通过
MoveIt 规划并检查完整路径、在 RViz 预览，再按二次确认的低速限制执行。该入口用于从
Cartesian Servo 无法起步的肘部/腕部奇异附近退出，不会关闭奇异、碰撞或关节限位保护。

演示与动作页顶部集中放置回原点和停止按钮，并可在同一处设置速度/加速度上限；
同步规划状态、抓取放置快捷按钮已从界面移除，真机与安全页不再堆放运动操作按钮。

MotionPlanning 使用原插件实例嵌入，不复制规划状态或按钮；其场景物体、已存场景、已存姿态、
状态和操作页面与禁区管理、动作库、联锁状态及安全抓放重复，因此只在综合面板中隐藏。
原独立 MotionPlanning 面板也会隐藏；综合面板被关闭或卸载时，原生页面会完整恢复。

RViz 只由 MotionPlanning 显示当前规划场景；独立 PlanningScene 显示默认关闭。示教专用
RobotState 只在 RViz 动作动画播放期间开启，结束后自动关闭，同时强制关闭 Planned Path
轨迹残影。自由规划的预计轨迹按规划时长播放一遍后自动清空，执行成功、失败、停止或离开
“自由运动规划”子页时也会立即清空；完整目标机械臂隐藏但橙色交互控制柄保留，因此不会在
主视图留下多台灰色机械臂。

真机快捷操作包括：

- **中文 / English**：运行时同时切换本控制面板和 MoveIt `MotionPlanning` 面板；
- **回原点 / Return Home**：用 MoveIt 从最新真机反馈规划并执行到当前型号 SRDF 的
  `home` 姿态；
- **停止当前操作**：取消 `/execute_trajectory` 的活动目标并停止操作进程。
- **启用/锁定 Xbox 控制**：通过 `/rebot_xbox/set_armed` 切换控制权；启用前要求手柄在线、
  输入未超时、摇杆回中、扳机松开且控制目标为机械臂，锁定会立即发送零速度；
- **摄像头标签页**：直接在 `reBot 综合控制`内部显示 Gemini 2 彩色画面，保持原始比例并
  随页面尺寸缩放；页面内也可打开/关闭摄像头。
- **打开/关闭摄像头**：启动 Orbbec Gemini 2 彩色、深度和深度对齐流；如果检测到外部
  `/camera/camera`，不会重复启动，也不会关闭外部进程，但摄像头标签页仍会显示彩色图。
- **展开/收起 Xbox 按键说明**：默认折叠；展开后用表格列出当前实测 Generic X-Box pad
  的按键、摇杆方向、功能以及仅限 `ARMED`、仅限 `LOCKED` 或始终可用等状态条件。

面板不会自行启动驱动，也不会自动运行演示。只有收到 1 秒内的关节反馈、并且 MoveIt
确认当前状态满足关节限位且没有碰撞时，按钮才可用。每次启动前还会要求操作员确认。
回原点和演示操作的速度/加速度默认限制为 5%，可在 1%–20% 范围内调整。回原点每次也会
要求真机确认；若当前位置、目标零位或规划路径存在碰撞，MoveIt 会拒绝执行。

面板还显示 Xbox 控制权：只有 `/rebot_xbox/armed=false`、界面显示 `LOCKED
(MoveIt 可执行)` 时，回原点和演示按钮才可用。Xbox 与 MoveIt 可以同时运行，但不能同时
向机械臂输出命令；按 A 或使用面板按钮切到 `ARMED` 会取消面板发起的活动规划轨迹，并把
控制权交给手柄。

回原点操作每次规划成功后都会把轨迹发布到 `/display_planned_path`。RViz 会先循环
播放半透明的预计运动约 2 秒，再开始驱动真机；这段时间可以点击“停止当前操作”取消。

真机 DM 启动入口：

```bash
source /home/w/project/rebotarm/real_robot_ws/activate.sh
ros2 launch rebot_xbox_hardware xbox_hardware_servo.launch.py \
  model:=dm channel:=/dev/ttyACM2
```

RViz 打开后使用右侧 **reBot 综合控制** 面板。演示坐标仍来自
`rebotarm_moveit_demos/config/`；首次现场运行前必须核对坐标、工装和碰撞场景。

拖动示教 `rebot_teach_mode` 是另一套功能，DM 组合入口会同时启动。按 X 录制、B 回放；
刚录完、选择/重载动作及开始回放时，轨迹同样显示在本 RViz 的 Planned Path 中。

右侧面板的 **演示与动作 -> 单动作与形状** 页面包含：

- **关节坐标动作**选项复用双臂动作点编辑器，可直接输入 J1–J6 角度、设置规划速度、命名保存
  动作点，并将多个动作点按顺序组合成动作序列；机械臂切换后使用各自独立的数据和关节限位；
- 动作下拉框和“刷新”用于选择已保存的 DM 动作；切换到“＋ 增加动作”会立即停止并清除
  旧动作的 RViz 轨迹。“复制”保留原轨迹、说明和绘图参数并要求输入新名称；“删除”会先
  弹出二次确认。为避免破坏
  已保存的动作序列，被序列引用的动作包必须先从相关序列中移除后才能删除；
- **绘图形状动作包**可选择矩形、三角形、圆形、五角星、心形、英文/数字/常用符号，或将
  本地图片提取并简化为简笔画轮廓；多笔画之间自动抬笔。点击“生成并加入示教动作”
  会以当前关节姿态为起点和终点，并使用 RViz 中橙色六自由度形状标记的当前位置与方向，
  通过 MoveIt 规划进场、连续绘图和退场轨迹，再保存为普通示教动作。当前形状以橙色填充面
  和粗轮廓高亮，可直接拖动；左侧 XYZ/RPY 输入框用于精确调整位置方向，W/H 输入框改变
  实际绘图尺寸。进入示教页时 MoveIt 自身重叠的目标球和大旋转环会隐藏。三色箭头调整 XYZ，旋转环
  调整绘制平面，黄色 W/H 方块可在三维空间直接拖动宽高；切换形状保留位姿，也可隐藏或
  恢复默认位姿。拖动和生成阶段均不驱动真机；
- “预检当前笔尖轨迹”会用虚拟笔碰撞体逐点检查 MoveIt IK：绿色可达、黄色接近关节限位、
  紫色碰撞、红色无 IK，断续段表示抬笔转移。若搜索到附近全路径可达的位置，只有经确认才会
  更新 RViz 画布，真机不会运动；
- 预检失败会明确列出无 IK 与碰撞（包括禁区）点数，并询问是否移动到搜索到的最近可行位置；
  移动后必须再次预检。
- 形状选择器始终显示当前图形的二维缩略图；选择“不添加图形（自由拖动录制）”会清除
  三维预设形状，随后直接使用“开始拖动录制/停止并保存”记录手动拖动出的任意轨迹；
- “开始拖动录制”/“停止并保存”可以不用 Xbox 完成示教；
- “播放 RViz 动画”只播放完整预计轨迹，不动真机；
- RViz 预览进度滑动条可检查任意时刻姿态，拖动松手后更新，绝不发送真机命令；
- “真机回放”会再次弹出安全确认，并由示教节点执行低速回放；
- “取消”用于中止当前录制或 RViz 预览；真机回放期间按钮显示为“取消回放并自动回原点”。
  面板会先等待轨迹控制器确认停止，再复用 `go_home` 的 MoveIt 无碰撞规划，以“真机与安全”页
  当前速度/加速度回到型号对应的 Home。若进入故障、Xbox 不再为 `LOCKED`、反馈超时或当前
  MoveIt 状态无效，则只保持停止，不会自动运动。

“动作组编排”页可勾选本次要执行的动作，RViz 动画与真机回放都只执行勾选项并保持列表顺序；
保存动作组仍保存完整列表。该页有独立的真机倍速、当前动作/总体真机进度和可拖动的 RViz
预览进度条，开始播放时会清除单动作轨迹和形状标记。顺序动画可使用该页的“暂停/继续 RViz
动画”和“取消 RViz 动画”；真机动作组回放时同一取消
按钮会停止当前动作、清空后续队列，并在控制器确认停止后按上述安全规则回 Home。真机回放
不提供中途暂停续播，与单动作一致。边界误差超过 `0.01 rad` 时，真机开始运动前会用 MoveIt/OMPL 为不重合的动作边界
预先生成带碰撞检查的过渡路径；任一边界规划失败时整组不启动。RViz 顺序动画也会预先规划并
连续显示相同的边界过渡，规划失败时拒绝播放；真机回放期间显示的橙色执行轨迹包含实际过渡。

“真机与安全”页会显示三维禁止通行区域管理器是否在线、已加载/已启用/已定义区域、活动区域组
和实际配置文件，并提供“重新加载禁区”按钮。已启用区域作为红色 MoveIt Planning Scene
碰撞几何体显示在 RViz 主视图，同时限制 MoveIt 与 Xbox Servo；重新加载不会移动真机。
同一卡片内可新建长方体、球体、圆柱体、圆锥体禁区，或上传 `.stl`/`.obj` 三维网格，设置
模型缩放及 XYZ/RPY 后导入。用户禁区持久化到
`~/.ros/rebotarm/forbidden_zones_user.yaml`，并可从面板安全删除。用户禁区在主视图中另有红色
六自由度模型，可直接平移或旋转；碰撞对象在拖动时跟随，松开鼠标后自动保存。还可多选用户
禁区保存为命名组。基础安全区不可拖动。RViz 仅显示真正的碰撞禁区，不叠加几何可达边界球。

自由运动规划失败时，规划页会显示具体说明：MoveIt 未找到无碰撞路径，并提示检查已启用禁区、
