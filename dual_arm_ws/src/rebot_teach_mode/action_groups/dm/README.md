# reBotArm DM 示教动作组库

DM 拖动示教生成的 `*.teach.json` 文件保存在此目录。文件包含型号标识和六轴关节轨迹，
不能在 RS 机械臂上回放。

内置两套由 12 个三秒静止采样动作组成的命名动作组：

- `自动手眼标定_DM_12姿态`：眼在手外，相机固定在外部，AprilTag 安装在夹爪上。
- `自动手眼标定_DM_眼在手上_12姿态`：眼在手上，相机安装在末端，AprilTag 固定在环境中；
  为尽量保持固定标签在末端相机视野内，摆动范围比眼在手外预设更小。

手眼标定启动器只监听与当前标定模式匹配的动作组。真机回放时逐姿态检查目标到位和
AprilTag TF，自动采样并在结束后计算、保存；模式或动作顺序不匹配时拒绝执行自动标定。
普通动作组回放不会触发该行为。首次现场使用必须先检查完整 RViz 预览和标签可见性。
