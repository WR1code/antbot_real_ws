# reBotArm 示教动作组库

通过命名录制或 `/rebotarm/teach/save_action_group` 保存的 RS `*.teach.json` 文件默认写到
此目录；DM 文件写到 `dm/` 子目录，避免跨型号误回放。
每个文件是一条带时间的六轴拖动示教轨迹，不是 Piper-H 的 `.motion.json` 动作点组，
两种文件不能互相导入。

RViz “绘图形状动作包”生成的 `形状包_*` 也使用同一格式和型号隔离目录；它们由 MoveIt
在现场当前姿态与碰撞场景下生成，不应跨机械臂或跨工装直接复制使用。

现场验证通过且需要长期复用的动作组可以纳入版本管理；临时动作、包含真实实验数据
或尚未验收的文件不要提交。
