## 总线隔离

MCU FDCAN1/FDCAN2 与 Linux can0 是不同总线域；不能把 Linux can0 当底盘总线。当前默认两臂是 reBotArm+Piper-H，不是两台 Piper。Piper 的右侧安装有 launch 注释证据；reBotArm 是否物理左臂仍 NEED_CONFIRMATION。CAN-FD 控制器名称不证明线上使用 CAN-FD 帧。

设备发现统计：上述前16条为硬件/候选记录，其中 UMA-8 为未发现；急停是待验证安全回路。不要把候选数当实机设备数。
